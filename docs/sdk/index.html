Reading and disclosure

Does the SDK require a framework?

No. The browser bundle enhances semantic HTML. The npm package also exports functions for pages built with a bundler.

Do theme preferences sync between subdomains?

No. Preferences are saved in local storage for the current origin. Sharing component code does not share browser storage.

Use the SDK

This checkout contains version 0.2.0. npm and public CDN URLs become available after publication; use the local bundle or a packed tarball until then.

Copy the complete distribution to shared/sdk/, including assets/, then use relative links from your page.

Script tag / self-hosted files

<script src="shared/sdk/idy-site.min.js"></script>
<link rel="stylesheet" href="shared/sdk/idy-site.css">
<body class="idy-site">…</body>

Load the script in the head before styles to apply saved preferences before paint. Keep assets/ alongside the CSS.

npm / ESM

import '@idy/site-sdk/style.css';
import { initSite, createHeader, enhance } from '@idy/site-sdk';

const site = initSite({ en: { heading: 'Projects' }, zh: { heading: '项目' } });
const header = createHeader({ siteName: 'My project', siteHref: '/' });
document.body.prepend(header);
enhance(header);

Prefer authored HTML for core navigation so it remains available without JavaScript. Factories are useful for client-rendered pages.
