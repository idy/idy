# Third-party notices

The distribution includes Archivo for all text and the existing Phosphor icon font for compatible header controls. Their full license texts ship alongside the font files in `dist/assets/`.

| Asset | License file |
| --- | --- |
| Archivo | `assets/Archivo-OFL.txt` |
| Phosphor icons | `assets/Phosphor-MIT.txt` |

Historical 0.1.0 distributions retain their original fonts and notices. These notices cover bundled third-party assets. The SDK's own license is not yet selected; package metadata uses `UNLICENSED` until the repository owner chooses one.
